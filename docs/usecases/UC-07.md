# UC-07 Admin reviews machines, sessions, faults and utilization

Actor: Location Admin. Stories: US-06, US-07, US-08.

## Main flow
1. The admin opens the Location overview: machines with state, devices online or offline, open tickets with ETA.
2. The admin lists bookings and sessions with filters (machine, status, dates).
3. The admin requests a utilization report for a date range: occupied hours against available hours per machine per day, and the number of faults.

## Rules
- Utilization counts Completed and Active bookings; Cancelled and NoShow do not count.
- Reports read from Booking and Maintenance data; no cross-schema joins in code, the API composes the result.
- Raw readings are kept 3 days; reports use bookings and tickets, not raw readings.
