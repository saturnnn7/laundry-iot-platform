# UC-02 Browse machine availability

Actor: Resident (member). Stories: US-10, US-11, US-28, US-29.

## Main flow
1. The resident opens a Location and optionally filters by kind (washer or dryer).
2. The platform returns every machine with its operational state: Available, Reserved, InUse or OutOfService.
3. For a chosen day the platform shows free 15-minute slots per machine.
4. For an InUse machine it shows the remaining time from telemetry.

## Alternatives
- The device is offline (cycle state Unknown): the machine is shown with `offline: true` and cannot be started; scheduled bookings stay allowed.
- A machine with an open ticket shows the ETA when one is set.

## Rules
- The operational state is derived (see state-machines.md): OutOfService flag, then running or Active, then Reserved, otherwise Available.
- Availability is owned by Booking and composed from Resources, Telemetry and Booking data through Contracts.
- The client polls; no push in the first version.
